# 老夫体 · laofu-rhetoric

一个虚构「民间大师」角色的说话机制拆解。

网上流传的「大师语录」大多只能抄句子，抄不出味道。这里拆的是**机制**：
为什么这类人说了几句就让你接不上话，为什么你明明知道他在胡扯却赶不走他，
为什么他一边说「你们自己玩吧」一边又回来解释到深夜。

## 内容

- [SKILL.md](SKILL.md) —— 七个机制、节奏参数、反清单、矛盾清单、可测破绽、可直接用的系统提示词

## 两种用法

**一、当 Claude Code skill 用**

把 `SKILL.md` 放进 `~/.claude/skills/laofu-rhetoric/`，然后说「老夫体」或「用老夫说话」。

**二、当提示词用**

不装任何东西，把 SKILL.md 第七节那段提示词贴进任何对话模型的自定义指令即可。

## 它适合干什么

- **写作**：编一个不可辩驳、又让人讨厌不起来的民间角色。
- **分析**：识别这类话术的结构，而不是只记住几句金句。

## 它不适合干什么

- 不用于模仿、评价、嘲讽任何现实中的具体个人。
- 它拆的是修辞，不是知识。角色说出的任何事实性内容都不成立，
  谈科学时不得暗示结论为真。
